### P1｜长征：道路从困境中展开

**时间：1934年10月—1935年1月**

**正文：**

1934年10月，中央红军撤离中央革命根据地，开始长征。第五次反“围剿”失败后的战略转移，意味着离开熟悉的根据地，面对封锁、追击和难以预知的前路。[S1]

湘江战役后，严峻的损失使前进方向成为必须回答的问题。红军随后转兵贵州。1935年1月，党中央在遵义召开会议，在危急关头纠正军事指挥等方面的错误，使中国革命迎来重要转折。[S2]

地图上的折线，在这里不只是地形的结果，也记录着对现实的判断和对道路的探索。

**地图动作：**依次点亮“于都→湘江战役区域→遵义”。先显示节点连接示意，实际折返与中间路径不由助手猜测。湘江节点标注“战役区域示意”，不可用一个点暗示全部战场。

**可选史料卡A｜为什么路线会改变？**

> 长征的前进方向并非从出发时就固定不变。湘江战役之后，红军根据敌情与自身处境调整行动。遵义会议前后的探索说明：坚定目标与根据实际情况改变走法，并不矛盾。[S2、S3]

卡片是说明问题的补充，不是让用户代替历史人物做军事决策。

### P2｜长征：在曲折中争取主动

**时间：1935年初—1935年夏**

**正文：**

遵义会议后，红军继续在敌军围追堵截中寻求突破。四渡赤水、巧渡金沙江、强渡大渡河、飞夺泸定桥，行进不是一条笔直的箭头，而是在复杂局势中不断争取主动。[S2、S3]

越过江河之后，还有高山与草地。严寒、饥饿和艰难的行军条件，考验着人的身体，也考验着队伍的组织与团结。长征能够继续，依靠指挥与判断，也依靠无数人的相互支撑。[S2]

我们今天看见的是一幅完整路线图；走在路上的人，面对的却是一个又一个尚待解决的难题。

**地图动作：**高亮黔北地区，再推进至金沙江、大渡河及川西；主图只显示阶段，不用少量点绘制“四渡赤水精确路线”。“四渡赤水”作为区域事件标签出现。若有可靠历史路线图并完成使用核查，后续可替换细节。

**小标签：路线变化 ≠ 信念动摇。**此句是作品阐释，可调整，不署历史人物名。

### P3｜长征：抵达，是新的开始

**时间：1935年10月／1936年10月**

**正文：**

1935年10月19日，中央红军主力到达陕北吴起镇。漫长的战略转移，在这里迎来重要的抵达。陕北成为革命继续发展的立足之地。[S4]

中央红军的抵达，并不等于所有红军队伍同时结束长征。1936年10月，红一、红二、红四方面军在以会宁为中心的甘肃中部地区胜利会师，标志着长征胜利结束。[S7]

长征留下的，不只是跨越山河的行程，还有在艰险中坚持理想、从实际出发寻找道路、依靠团结继续前行的精神力量。

**地图动作：**1935年主线路在吴起结束。1936年用独立时间标记和会师区域提示，不从吴起向会宁续画同一条“中央红军长征路线”。本版不假装覆盖其他各支红军的完整行程。

**图注：本图以中央红军长征主要节点为叙事线索；1936年会师另作补充标示。**

### P4｜转场：建设年代的回答

**时间：1955—1956年**

**正文：**

时间来到新中国建设时期。国家建设需要人才，西部发展需要教育与科技的支撑。1955年，党中央、国务院决定交通大学西迁；1956年，迁校付诸大规模行动。[S5]

这一次，需要跨越的不再是战争中的封锁线，而是原有的生活与工作格局。师生员工要迁移，仪器、图书与教学设备要搬运，新的校园要建设，教学与生活也要在新的土地上重新展开。

从长征到西迁，历史任务发生了变化。作品在这里追问：当国家需要与个人选择相遇，人们怎样作答？

**地图动作：**长征路线保留为淡红色，年份平稳切换；上海点亮，出现“1956·西迁”。不把长征终点变形成西安，不让一条线直接冒充另一条线。

### P5｜西迁：列车把课堂带向西部

**时间：1956年夏**

**正文：**

1956年夏，交大师生员工分批从上海前往西安。粉色乘车证上，印着“向科学进军，建设大西北”。这既是行程的方向，也是迁校的任务。[S5]

郑善维在回忆中记下了1956年8月10日出发的那趟专列：列车到达南京后，需要轮渡过江。车厢被分开送上渡船，再在对岸接续行程。对年轻学生而言，这是一段新奇的旅途；对迁校而言，它只是庞大组织工作中的一个环节。[S6]

地图上的上海与西安之间，运送的不只是旅客。迁校要让教学、实验与日常生活在西部继续运转，一所大学的功能也随之向新的地方展开。

**地图动作：**上海出发，经南京及线路参照节点向西安推进。只有南京等已见史料的地点可标“故事发生地”；用于表现走向的参照点不能写成已核实停靠站。

**可选史料卡B｜南京：火车也要坐船过江**

> 郑善维《在西去的列车上》记述了专列在南京轮渡过江的过程。本文据此改写这一细节，以呈现当时迁移工作的具体条件。该经历属于一趟专列，不代表所有西迁批次拥有完全相同的时间与行程。[S6]

**视觉巧思：**点击南京节点时，出现原创的简洁车厢与波纹线条示意，展示“分节—渡江—接续”。标注“据回忆文字绘制的示意”，不用现代大桥素材冒充1956年现场。

### P6｜西迁：到达之后，才是扎根

**时间：1956年起**

**正文：**

列车抵达西安，西迁的故事却没有结束。1956年9月10日，交通大学在西安人民大厦礼堂举行迁校后的首次开学典礼。抵达一座城市，开始转化为在这里办学、生活与建设。[S8]

郑善维后来留校工作，直至退休。他的回忆让“扎根”有了具体的时间尺度：一次出发，延伸为一生的学习与工作。[S6]

西迁精神被概括为“胸怀大局、无私奉献、弘扬传统、艰苦创业”。这些词语背后，是把个人发展放进国家需要，也是在迁移之后持续建设的日常。[S5]

**地图动作：**路线停止在西安，节点由空心变实心；出现“迁移→办学→扎根”三个词。此后不继续增加虚构路径，以文字表现时间延伸。

### P7｜尾声：今天，我们怎样继续

**时间：今天**

**正文：**

长征与西迁，不是同一段历史。前者在革命的危急关头开辟前路，后者在建设年代调整教育布局、支援西部。把它们放在一起，是为了看见不同年代中相通的担当。

对今天的交大学生而言，理解这种担当，可以从认真完成一次实验、扎实推进一项研究、走近真实的社会问题开始。选择未必总是远行，但应当知道自己的知识与行动，能够回应什么需要。

### 3.4 可直接生成的无底图坐标草图

开发时使用统一的SVG坐标空间，先不用真实行政边界。为确保大致方位及地理比例一致，按以下区域进行等距圆柱近似转换：经度范围100—123，纬度范围24—39，中纬度31.5°。

```python
import math

LON_MIN, LON_MAX = 100.0, 123.0
LAT_MIN, LAT_MAX = 24.0, 39.0
W, H = 1000.0, 800.0
PAD = 60.0
C = math.cos(math.radians(31.5))
scale = min((W - 2*PAD) / ((LON_MAX-LON_MIN)*C),
            (H - 2*PAD) / (LAT_MAX-LAT_MIN))
map_w = (LON_MAX-LON_MIN)*C*scale
map_h = (LAT_MAX-LAT_MIN)*scale
left, top = (W-map_w)/2, (H-map_h)/2

def project(lon, lat):
    return (left + (lon-LON_MIN)*C*scale,
            top + (LAT_MAX-lat)*scale)
```

SVG使用`viewBox="0 0 1000 800"`；路线和节点都通过同一个project函数计算。该草图无行政底图，只用于交互原型。不得把按此函数算出的节点直接叠到任意PNG底图上：正式底图必须核对投影与配准，选择兼容的坐标转换，或使用人工校准且明确记录的图像坐标。

若地图素材尚未落实，正式页面可以暂时保留清晰注明的节点示意版本，但上线前仍须检查地图表达与使用要求。“示意”标签不能替代地图核查。

### 4.5 动画与阅读

- 章节切换：300—500ms的淡入、路线揭示和节点高亮；不是每段文字逐字出现。
- 路线为SVG分段path；正式线路不是点间直线时，每段可以存path字符串。
- 实线揭示可用stroke-dasharray/dashoffset。赭金虚线需要额外遮罩或独立揭示层，不能用同一dasharray同时承担虚线样式和绘制进度，避免动画后变实线。
- 地图默认固定视域，第一版不做跟随滚动不断缩放、平移的镜头。
- 尊重prefers-reduced-motion，减少动态时直接展示当前状态；无JavaScript时正文及静态总览仍可读。
- 节点详情支持点击和键盘操作，不只支持hover。弹层支持Esc关闭、焦点留在弹层内，关闭后回到触发点。
- 来源标记如“[1]”可点击打开来源列表或对应条目；不在正文段落里堆完整URL。
