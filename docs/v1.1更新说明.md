# v1.1增量更新说明

## 使用方法

本补丁仅包含相对于v1.0新增、修改的文件。解压后把其中`site/`、`tools/`、`docs/`和根目录文件，按原路径合并覆盖到现有`shanhe-h5`项目根目录；不要把补丁目录当成一个全新项目单独启动。

不会覆盖`site/config.js`、Pages工作流和GitHub账户配置。原有`.github/workflows/pages.yml`继续使用。覆盖前建议先提交一次自己的Git改动，避免丢失个人修改。

覆盖后运行：

```bash
python tools/check_project.py
python -m http.server 8000 --directory site
```

浏览器强制刷新后查看。同步到GitHub仍是Commit、Push，Pages工作流自动发布。

1. 加入浅色省级行政区背景与省名，路线、节点、省界使用同一投影。
2. 加入原创红旗、五角星、书本、列车和书信图标，辅以红色印章及飘带装饰。
3. 移除阅读区中的坐标精度、无行政底图、字体子集、未使用照片等技术性措辞；保留简短图片图注与史料链接，维护记录放入文档。
4. 主标题与副标题换为源自Ma Shan Zheng的开源书法字体，本地加载；章标题继续保留可读性较好的宋体。

6. P7结合2026年4月7日回信，引出科技创新、人才培养与实践行动。

## 技术与素材维护

- `tools/build_static.py`调用新增`tools/presentation_v2.py`绘制省界并生成本轮页面增强。保留`tools/data/provinces.json`后即可离线重建，不依赖在线地图API。
- P7及图文卡片内容位于`tools/presentation_v2.py`，来源及图片弹层信息位于`site/data.js`。
- 源数据、字体许可证与图片出处详见根目录`THIRD_PARTY_NOTICES.md`。照片公开可见与取得转载许可不能混同；不把新闻图片宣称为开源素材。
- 地图背景为现行省级空间参照；路线仍是主要节点连接，不是新获得的精确轨迹。这些维护说明不再铺在作品正文中。
- 原档案图有低分辨率版本，保持原始图像，不进行AI补画或移除水印。

## 检查范围

本轮执行文件／锚点／模块／SVG／字体检查、JavaScript语法检查，以及DOM模拟交互回归，覆盖章节切换、反向滚动、来源与史料弹层、新增4幅图片弹层、行政区层存在性和回信段落。

额外对生成的SVG地图进行了静态图面检查。当前仍未进行真实浏览器页面渲染或微信实机测试；固定地图、手机标签密度与弹层焦点行为请部署后复核。
